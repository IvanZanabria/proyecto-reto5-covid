# Proyecto Final - Arquitecturas de Datos Masivos (Reto 5)
**Tema:** Trazabilidad y propagación epidemiológica (COVID-19 Colombia - 639,097 registros).
**Integrantes:** [Ivan Moreno] y [Jhon Herran]

## Arquitectura
- **Ingesta:** Apache Kafka
- **Data Lake:** Amazon S3
- **Procesamiento:** Apache Spark
- **Almacenamiento Operativo:** Apache Cassandra
- **Grafos y Trazabilidad:** Neo4j
- **Analítica:** BigQuery / Snowflake
